# Deepfake-Audio-Detection-Using-Hybrid-Models-LSTM-and-Transformer
An MSc Data Science project in which variety of models were employed, including Random Forest, SVM, CNN, LSTM, Transformer, and a Hybrid Transformer-LSTM. Their performance was quantified according to the indicators of accuracy, precision, recall, F1-score, Equal Error Rate (EER), and ROC-AUC in an aggregated construct.
